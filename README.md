# 🛒 Java Store System

Um mini projeto desenvolvido em Java com o objetivo de praticar os conceitos de **Programação Orientada a Objetos (POO)**, aplicando herança, classes abstratas, interfaces, encapsulamento e polimorfismo.

Este projeto faz parte da minha jornada de estudos em Java e será evoluído conforme novos conteúdos forem sendo aprendidos.

---

## Conceitos praticados

* Encapsulamento
* Herança
* Classes abstratas
* Interfaces
* Polimorfismo
* Sobrescrita de métodos (`@Override`)
* Organização em pacotes
* Boas práticas de orientação a objetos

---

## Funcionalidades

* Cadastro de diferentes tipos de produtos.
* Cálculo individual de impostos para cada produto.
* Armazenamento dos produtos cadastrados.
* Listagem de produtos.
* Busca de produtos por nome.
* Cálculo do valor total da loja.
* Remoção de produto.
* Identificação do produto mais caro e mais barato.
